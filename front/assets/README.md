Coloca aquí dibujos PNG listos para colorear.

Requisitos recomendados:

- Líneas oscuras sobre fondo blanco.
- Contornos cerrados para evitar fugas del balde.
- Resolución cercana a 1000-1200 px por lado.
- Sin anuncios, marcas de agua ni fondos con textura.
- Agregar cada dibujo nuevo en `../assets-list.js`.

Validación antes de publicar:

- Ejecutar `file assets/*.png` desde la raíz.
- Confirmar que no haya imágenes innecesariamente mayores a 1200 px por lado.
- Pintar cada imagen en la web y revisar bordes, esquinas y detalles finos.
